# geometric_lib

Библиотека для вычисления площадей и периметров плоских геометрических фигур.

## Общее описание решения

Проект представляет собой набор независимых Python-модулей, каждый из которых
отвечает за одну геометрическую фигуру. Все модули предоставляют единый
интерфейс из двух функций: `area()` — вычисление площади и `perimeter()` —
вычисление периметра.

### Структура проекта

```
geometric_lib/
- circle.py       # круг
- square.py       # квадрат
- rectangle.py    # прямоугольник
- triangle.py     # треугольник
- test_circle.py     # unit-тесты для circle.py
- test_square.py     # unit-тесты для square.py
- test_rectangle.py  # unit-тесты для rectangle.py
- test_triangle.py   # unit-тесты для triangle.py
- docs/
    - README.md   # документация
```

## Описание функций

### Модуль `circle.py`

#### `area(r)`

Вычисляет площадь круга по формуле S = πr².

| Параметр | Тип | Описание |
|---|---|---|
| `r` | float | радиус круга |

**Возвращает:** `float` — площадь круга.

```python
>>> circle.area(1)
3.141592653589793
```

#### `perimeter(r)`

Вычисляет периметр круга по формуле P  = 2πr

| Параметр | Тип | Описание |
|---|---|---|
| `r` | float | радиус круга |

**Возвращает:** `float` — периметр круга.

```python
>>> circle.perimeter(1)
6.283185307179586
```

### Модуль `square.py`

#### `area(a)`

Вычисляет площадь квадрата по формуле S = a².

| Параметр | Тип   | Описание         |
| -------- | ----- | ---------------- |
| `a`      | float | сторона квадрата |

**Возвращает:** `float` — площадь квадрата

```python
>>> square.area(5)
25
```

#### `perimeter(a)`

Вычисляет периметр квадрата по формуле P = 4a.

| Параметр | Тип   | Описание         |
| -------- | ----- | ---------------- |
| `a`      | float | сторона квадрата |

**Возвращает:** `float` — периметр квадрата.

```python
>>> square.perimeter(5)
20
```

### Модуль `rectangle.py`

#### `area(a, b)`

Вычисляет площадь прямоугольника по формуле S = ab.

| Параметр | Тип   | Описание             |
| -------- | ----- | -------------------- |
| `a`      | float | длина первой стороны |
| `b`      | float | длина второй стороны |

**Возвращает:** `float` — площадь прямоугольника

```python
>>> rectangle.area(3, 4)
12
```

#### `perimeter(a, b)`

Вычисляет периметр прямоугольника по формуле P = 2(a + b).

| Параметр | Тип   | Описание             |
| -------- | ----- | -------------------- |
| `a`      | float | длина первой стороны |
| `b`      | float | длина второй стороны |

**Возвращает:** `float` — периметр прямоугольника.

```python
>>> rectangle.perimeter(3, 4)
14
```

### Модуль `triangle.py`

#### `area(a, h)`

Вычисляет площадь треугольника по формуле S = ah/2.

| Параметр | Тип   | Описание                            |
| -------- | ----- | ----------------------------------- |
| `a`      | float | длина основания                     |
| `h`      | float | длина высоты, опущенной к основанию |

**Возвращает:** `float` — площадь треугольника

```python
>>> triangle.area(6, 4)
12.0
```

#### `perimeter(a, b, c)`

Вычисляет периметр треугольника по формуле P = a + b + c.

| Параметр | Тип   | Описание              |
| -------- | ----- | --------------------- |
| `a`      | float | длина первой стороны  |
| `b`      | float | длина второй стороны  |
| `c`      | float | длина третьей стороны |

**Возвращает:** `float` — периметр треугольника.

```python
>>> triangle.perimeter(3, 4, 5)
12
```
## Тестирование

Для каждой фигуры написаны unit-тесты на стандартном модуле `unittest`
(по 6 тестов на модуль, всего 24): нулевое значение, целые и дробные входные данные
для `area()` и `perimeter()`. Дробные результаты сравниваются через `assertAlmostEqual`.

Запуск всех тестов из корня проекта:

```bash
python3 -m unittest -v
```
